# iClicker Manufacturing Planning System

Python based production planning and MRP simulator inspired BOM calculator from coursework ME170 and SAP PP

## Project Overview

The system determines the materials required for a planned production quantity, compares material requirements against current inventory, identifies shortages, and generates purchase recommendations.

## Workflow

Production Plan
→ Bill of Materials (BOM)
→ Material Requirements Planning (MRP)
→ Inventory Check
→ Shortage Analysis
→ Purchase Order
→ Procurement Cost

## Features

- Bill of Materials (BOM) management
- Production quantity planning
- Material requirements calculation
- Inventory availability checking
- Shortage identification
- Purchase quantity recommendations
- Supplier information
- Procurement cost calculation
- Integrated manufacturing planning workflow
